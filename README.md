### 🚀 Things I've Built

**🤖 AI Job Application Tracker**
*AI-powered career command centre — parse → score → tailor*
An agentic job-tracking platform built on the Lemma SDK, cutting manual tracking time by ~80% per application.
- 3-stage agentic intake pipeline extracting 8+ structured fields from raw job descriptions in under 3 minutes
- Automated cover letter & resume tailoring via multi-agent workflows — 45 min of prep down to under 5 min
- Real-time dashboard with pipeline funnel, AI insights, and follow-up nudges across 50+ applications and 5+ sources
- Deployed with 6 datastores, 5 AI agents, 3 workflows, and 1 scheduled weekly review agent
`Lemma SDK` · `TypeScript` · `React` · `Vite` · `Claude Sonnet 4.6` · `Python`

**🚨 Smart Crowd Evacuation System**
*Real-time emergency routing simulator*
An evacuation simulator using weighted Dijkstra pathfinding, cutting average path risk scores by up to 40% vs. shortest-path routing.
- Dynamic real-time agent rerouting across 3 environmental states (clear, congestion, danger zones)
- Multi-agent collision avoidance across 3+ configurable exits with randomized crowd scatter
- 3 preset layouts (stadium, office, mall) with a live inference panel explaining routing decisions
- Crowd heatmap overlay + speed/delay system modeling up to 3× slowdown in congested zones
`NumPy` · `Matplotlib` · `heapq` · `collections.deque` · `JavaScript` · `HTML5` · `CSS3`

**🔥 Forest Fire Prediction**
*Machine learning for early disaster detection*
A prediction model assessing forest fire likelihood from environmental and climatic data, to support early detection and disaster management.
`Machine Learning` · `Python` · `Pandas` · `NumPy` · `Scikit-learn` · `Matplotlib` · `Jupyter Notebook`
